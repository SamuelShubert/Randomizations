# Randomizations

Created after the first ever massive milestone in my programming journey: an app for iPhones called Randomizations, published on the App Store in 2018 (no longer available for download).

This web version does the same job: roll dice, pick a random number or letter, or let it choose from your own list (typed in or uploaded as a CSV).

Visit https://samuelshubert.github.io/Randomizations/ to try it out
